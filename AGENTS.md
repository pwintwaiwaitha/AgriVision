# AgriVision Repository Instructions

Before changing any AgriVision application code, read `README.md` and every file in
`context-kit/` completely. Treat them as the project's development source of truth.

Start with the repository audit in `context-kit/15-builder-master-prompt.md`. Preserve
working code and user changes. Use the three-track model, enforce consent and safety,
label all data honestly, and never invent values for the six charts.

After verified work, update `context-kit/14-progress-tracker.md` with completed items,
test results, unresolved issues, and the latest run information.
